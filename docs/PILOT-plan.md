# خطة التجربة الداخلية المحدودة — بوت السيفيات (مسودة)
> تجربة مغلقة — لا إعلانات عامة، لا رسائل جماعية، لا معاملات مالية حقيقية.

## الهدف
اختبار حقيقي للبوت بمستخدمين مختلفين (يسد فجوة «التزامن غير مختبر حيًا») قبل أي إطلاق عام.

## المشاركون (3–5 أشخاص)
- يختارهم طه بنفسه من معارفه الموثوقين (مقترح: هادي + 2–4 آخرون).
- يُبلغ كل مشارك كتابةً أنها **نسخة تجريبية**: الخدمة مجانية للتجربة، والمدفوعات وهمية.

## وضع الدفع في التجربة
- المشاركون يرفعون **إيصالات اختبار** (أي صورة) ويكتبون رقم الطلب بالملاحظة.
- الإدارة (طه) توافق عليها كطلبات اختبار — تُوسم تلقائيًا ضمن بيانات التجربة.
- **ممنوع أي تحويل مالي حقيقي** خلال التجربة.

## سيناريو كل مشارك
1. /start → إنشاء سيرة كاملة (عربي أو إنجليزي حسب اختياره).
2. الوصول لخطوة الدفع → رفع إيصال اختبار.
3. الإدارة توافق → استلام PDF + DOCX + خطاب التقديم.
4. طلب تعديل واحد (اختبار رصيد التعديلات المجانية).
5. (اختياري) مشاركان يبدآن بنفس الوقت لاختبار التزامن الحقيقي.

## المراقبة (Muse)
- مراقبة اللوغات لحظيًا أثناء الجلسات التجريبية: أخطاء، اختلاط بيانات، أزمنة استجابة.
- تسجيل كل عطل في تقرير التجربة مع سببه وإصلاحه.

## معايير النجاح
- 5/5 رحلات مكتملة دون أخطاء حرجة.
- صفر اختلاط بيانات بين المستخدمين.
- رضا المشاركين عن وضوح الخطوات (استبيان شفهي قصير).

## المدة المقترحة
3–5 أيام من بدء دعوة المشاركين.

## بعد التجربة
- تقرير نتائج → قرار طه: تنظيف بيانات الاختبار/التجربة → الإطلاق العام.
