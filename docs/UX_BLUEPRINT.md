## شاشات المستخدم

### U01 — START / القائمة الرئيسية
- **الهدف:** ترحيب + عرض السعر + دخول
- **النص:** «👋 أهلًا بيك ببوت *السيفي الاحترافي* — سيفي PDF + Word بـ *5,000 د.ع* فقط...»
- **الأزرار:** [📄 إنشاء سيفي جديد] [📁 طلباتي وملفاتي] [🎤 تدريب المقابلات] [🧠 ذاكرتي المهنية] [❓ المساعدة]
- **السلوك:** إنشاء سيفي → U02 (أو استئناف مسودة U09X إن وجدت). طلباتي → U20. تدريب → U30. ذاكرة → U40. مساعدة → U50
- **الرجوع:** لا يوجد (شاشة جذر). `/cancel` يعود هنا
- **البيانات:** لا شيء. **الصلاحيات:** الجميع

### U02 — نوع الخدمة
- **الهدف:** تحديد مسار المقابلة
- **النص:** «شنو نوع السيفي اللي تريده؟»
- **الأزرار:** [🎯 وظيفة محددة] [📝 سيفي عام] [🎓 خريج جديد] [🔄 تغيير مسار مهني] [👔 خبرة طويلة/إدارية] [🔙 رجوع]
- **السلوك:** يحفظ `service_type` → U03. رجوع → U01
- **البيانات:** service_type

### U03 — المجال المهني
- **الهدف:** تخصيص الأسئلة والمهارات والقالب
- **الأزرار:** [🏥 طب/صيدلة] [💻 تقنية IT] [🏗 هندسة] [🧮 محاسبة/مالية] [📚 تعليم] [📣 تسويق] [💼 مبيعات] [🔧 فني/حرفي] [📦 أخرى] [🔙]
- **السلوك:** يحفظ `field` → U04

### U04 — تفاصيل الوظيفة المستهدفة
- **الهدف:** المسمى + السوق + المستوى + اللغة
- **النص:** أسئلة متسلسلة بأزرار:
  1. «اكتب المسمى الوظيفي» (نص حر مرة واحدة) → أزرار [✅ حفظ] [✏️ تعديل]
  2. «سوق العمل؟» [🇮🇶 العراق] [🌍 الخليج] [🌐 دولي/ريموت]
  3. «مستواك؟» [🌱 مبتدئ] [⚙️ متوسط] [🚀 متقدم] (يحدد سقف المهارات: 6/8/10)
  4. «لغة السيفي؟» [🇮🇶 عربي] [🇬🇧 English] [🌍 الاثنين]
- **السلوك:** كل إجابة تُحفظ فورًا (مسودة تلقائية) → بعد اللغة U05

### U05 — اختيار القالب
- **الهدف:** عرض القوالب الجاهزة فقط مع وصفها
- **النص:** «🎨 اختر القالب — كلها تشمل PDF + Word»
- **الأزرار:** (تُبنى ديناميكيًا من القوالب الجاهزة فقط)
  `[ATS Minimal — عربي: بسيط، متوافق مع أنظمة التوظيف]`
  `[ATS Professional — English]`
  `[Modern Corporate — عربي: عصري للشركات]`
  `[Modern Corporate — English]`
  `[🔙 رجوع]`
- **السلوك:** اختيار → U06 (معاينة القالب). القالب غير الجاهز **لا يُعرض إطلاقًا**
- **البيانات:** template_id

### U06 — معاينة القالب
- **الهدف:** معاينة حقيقية من محرك التوليد بعلامة مائية
- **النص:** صورة PNG (دقة منخفضة + علامة PREVIEW — NOT FINAL + إخفاء بيانات الاتصال)
- **الأزرار:** [✅ اختيار هذا القالب] [🔄 قالب آخر] [✏️ تعديل معلوماتي] 
- **السلوك:** اختيار → U07. قالب آخر → U05

### U07 — الصورة الشخصية
- **الهدف:** خيار مستقل عن التصميم
- **النص:** «تريد تضيف صورتك الشخصية للسيفي؟ (اختياري — قوالب ATS تُفضل بدون صورة)»
- **الأزرار:** [📷 نعم، أرفع صورة] [🚫 بدون صورة]
- **السلوك:** نعم → انتظار صورة (تحقق: صورة فعلية، حجم معقول) → U08. لا → U08
- **الأخطاء:** ملف غير صورة → «أرسل صورة بصيغة JPG/PNG»

### U08..U18 — المقابلة (جمع البيانات)
كل حقل شاشة مستقلة بنفس النمط:
- **النص:** سؤال واحد واضح + مثال
- **الأزرار بعد الإدخال:** [✅ حفظ ومتابعة] [✏️ تعديل] [⏭ تخطي] [🔙 رجوع] [❌ إلغاء القسم]
- **الحقول بالترتيب:** الاسم الكامل → الهاتف → الإيميل → العنوان → المسمى الوظيفي → الملخص (يُقترح تلقائيًا U19) → الخبرات (حلقة: مسمى/شركة/فترة/وصف + [➕ إضافة خبرة]) → التعليم → الشهادات → المهارات (U19B اختيار متعدد) → اللغات
- **إلغاء القسم ≠ إلغاء الطلب** — القسم يُحذف والطلب يستمر
- **البيانات:** كل حقل يُحفظ فورًا في المسودة (استئناف تلقائي)
- **قاعدة:** لا توليد بيانات وهمية — الفارغ يبقى فارغًا

### U19 — مراجعة الـ Summary المولد
- **الهدف:** عرض Summary المبني من بيانات المستخدم الحقيقية فقط
- **النص:** الـ Summary + «مبني من معلوماتك فقط — بدون إضافات»
- **الأزرار:** [✅ اعتماد] [✏️ تعديل يدوي] [🔄 إعادة توليد]
- **السلوك:** اعتماد → U19B

### U19B — اختيار المهارات
- **الهدف:** اختيار متعدد بسقف حسب المستوى (مبتدئ 6 / متوسط 8 / متقدم 10)
- **النص:** قائمة مهارات مقترحة حسب المجال + «اختر (0/6)»
- **الأزرار:** أزرار toggle لكل مهارة + [✅ تم] [➕ إضافة مهارة يدوية]
- **السلوك:** تجاوز السقف → تنبيه. المقترحة تُوسم (مقترحة — تحتاج تأكيد)

### U20 — المراجعة قبل الدفع
- **الهدف:** مراجعة شاملة + عدد الصفحات المتوقع
- **النص:** ملخص: القالب، اللغة، الوظيفة، الأقسام، الصفحات المتوقعة، السعر
- **الأزرار:** [👀 معاينة بعلامة مائية] [✏️ تعديل] [💳 المتابعة للدفع] [🔙]

### U21 — المعاينة الآمنة
- **الهدف:** معاينة نهائية قبل الدفع
- **النص:** صورة PNG (دقة منخفضة، علامة مائية متكررة، بيانات اتصال مُخفاة جزئيًا)
- **الأزرار:** [💳 ادفع الآن] [🎨 تغيير القالب] [✏️ تعديل المعلومات] [🔙]

### U22 — الدفع
- **الهدف:** تعليمات كي كارد
- **النص:** «💳 الدفع عبر كي كارد — الرقم: `[REDACTED]` — المبلغ: *5,000 د.ع* — رقم الطلب: `CV-XXXXXX` — اكتب رقم الطلب بملاحظة التحويل»
- **الأزرار:** [✅ دفعت الآن] [🔙 رجوع]
- **السلوك:** دفعت → U23. **البيانات:** payment_status=awaiting_receipt

### U23 — رفع الإيصال
- **الهدف:** استلام صورة الإيصال
- **النص:** «أرسل صورة إيصال التحويل»
- **الأزرار:** [🔙 رجوع]
- **السلوك:** صورة → payment_status=receipt_received → إشعار الآدمن (A03) → U24
- **الأخطاء:** غير صورة → طلب صورة. **قاعدة:** إيصال واحد = طلب واحد فقط

### U24 — بانتظار موافقة الإدارة
- **النص:** «✅ استلمنا الإيصال — جاري المراجعة»
- **الأزرار:** لا شيء (انتظار). `/cancel` لا يلغي بعد هذه النقطة
- **التالي:** موافقة → U25 (توليد) | رفض → U24R (سبب الرفض + إعادة رفع)

### U25 — التسليم
- **الهدف:** الملفات النهائية
- **النص:** «🎉 سيفيك جاهز!» + الملفات: PDF + DOCX (+ نسخة ثانية للغة الأخرى إن وجدت) + خطاب التقديم كنص
- **الأزرار:** [✏️ طلب تعديل (متبقي: 2 مجاني)] [🔧 الإبلاغ عن خطأ بالنظام] [📁 طلباتي]
- **البيانات:** status=delivered, payment_status=approved

### U26 — طلب تعديل
- **النص:** «رصيدك: X مجاني / Y مدفوع» + اختيار القسم + القيمة الجديدة
- **الأزرار:** قائمة الأقسام + [🔧 هذا خطأ من النظام (مجاني دائمًا)]
- **السلوك:** مجاني متاح → تنفيذ → خصم عند النجاح فقط. مدفوع → U26P (دفع 5,000)
- **القواعد:** لا خصم إلا عند تنفيذ ناجح. لا خصم مكرر. سجل استخدام

### U20B — طلباتي وملفاتي
- **الأزرار:** قائمة الطلبات (كل طلب: الحالة + أزرار عرض/تحميل/تعديل حسب الحالة)
- **الصلاحيات:** المستخدم يرى طلباته فقط (تحقق user_id على الخادم)

### U30 — تدريب المقابلات (مرحلة ثانية — أساسي مبسط)
- **التدفق:** اختيار الوظيفة → نوع المقابلة [عامة/فنية/سلوكية] → سؤال → إجابة المستخدم (نص/صوت) → تحليل AI (نقاط قوة/تحسين) → [سؤال جديد/تلميح/نموذج إجابة/إنهاء/ملخص]
- **الأزرار فقط**

### U40 — الذاكرة المهنية
- **النص:** طلب موافقة واضحة أول مرة: «تحفظ بياناتك المهنية لتسهيل المرات الجاية؟»
- **الأزرار:** [✅ أوافق] [❌ لا] | لاحقًا: [👀 عرض] [✏️ تعديل] [🗑 حذف]
- **القواعد:** لا خلط بين المستخدمين. عرض للتأكيد عند سيفي جديد (لا افتراض)

### U41 — استيراد من ملف قديم
- **النص:** «أرسل سيفيك القديم (PDF/DOCX/صورة)»
- **السلوك:** استخراج → تصنيف → عرض للمراجعة (مؤكد ✅ / يحتاج مراجعة ⚠️) → اعتماد → تعبئة الحقول
- **القواعد:** لا حذف تلقائي. لا توليد قبل اعتماد المعلومات المهمة

## شاشات الإدارة (صلاحيات: ADMIN_ID فقط — تحقق على الخادم)

### A01 — لوحة الإدارة الرئيسية
- **الدخول:** زر سري في U01 (⚙️ يظهر للآدمن فقط) أو أمر /admin
- **الأزرار:** [📊 نظرة عامة] [💳 مدفوعات معلقة (N)] [📋 كل الطلبات] [👥 المستخدمون] [🎨 القوالب] [🤖 الذكاء الاصطناعي] [⚙️ الإعدادات] [📝 سجل العمليات]

### A02 — نظرة عامة
- **النص:** إحصائيات حقيقية من DB: طلبات اليوم/الأسبوع، إيراد، معدل القبول، قوالب الأكثر استخدامًا

### A03 — بطاقة طلب دفع معلق
- **النص:** رقم الطلب، المستخدم، المبلغ، التاريخ، القالب/اللغة، صورة الإيصال
- **الأزرار:** [✅ موافقة] [❌ رفض] [🔍 طلب إيصال أوضح] [📄 التفاصيل]
- **السلوك:** موافقة → تأكيد «متأكد؟» → تسجيل (admin_id + الوقت) → منع التكرار → توليد → فحص جودة → تسليم. رفض → اختيار سبب من أزرار [غير واضح/مبلغ ناقص/إيصال مكرر/أخرى] → إشعار المستخدم
- **القواعد:** إيصال واحد = طلب واحد. فشل التوليد بعد الموافقة → إعادة آمنة بدون دفع جديد

### A04 — القوالب
- **الأزرار:** قائمة القوالب: [✅/❌ تفعيل] لكل قالب + الترتيب. القالب غير الجاهز لا يظهر للمستخدم أصلًا

### A05 — الذكاء الاصطناعي
- **النص:** الحالة: المفتاح [مُدخل ✅/مفقود ⚠️] | الموديل الحالي: `...` | آخر خطأ
- **الأزرار:** [🆓 موديلات OpenRouter المجانية] [🔑 إدخال/تحديث المفتاح] [🔙]
- **A05M — قائمة الموديلات:** تُجلب حيًا من OpenRouter، مجانية فقط، الحالي مُعلّم ✅، ترقيم صفحات. اختيار → حفظ + سجل تدقيق
- **A05K — المفتاح:** «أرسل المفتاح الجديد» (نص، يُحذف بعد الحفظ) → تشفير + حفظ + اختبار اتصال → «✅ يعمل» / «❌ فشل»
- **الأمان:** لا عرض المفتاح كاملًا أبدًا (إخفاء •••• + 4 أحرف)

### A06 — الإعدادات | A07 — سجل العمليات (تدقيق) | A08 — المستخدمون | A09 — كل الطلبات (تصفية بالحالة)

## رسائل النظام والأخطاء
- غير مدعوم: «عذرًا، أرسل صورة/نص حسب المطلوب» + زر رجوع
- انتهاء الجلسة: استئناف من المسودة تلقائيًا
- فشل AI: «الكتابة الذكية غير متاحة حاليًا — نستخدم الصياغة الأساسية» (وضع انتظار واضح)
- خطأ تقني بعد الدفع: «صار خلل تقني — نعيد التوليد مجانًا بدون دفع جديد»
