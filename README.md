# بوت السيفيات | CVBot 🤖📄

<p dir="rtl">
بوت تيليجرام تجاري متكامل لإنشاء السير الذاتية الاحترافية — يستلم معلومات المستخدم عبر المحادثة،
يولّد سيرة ذاتية بتصميم ATS متوافق مع أنظمة التوظيف، ويتعامل مع الدفع والمراجعة والتسليم بالكامل داخل تيليجرام.
</p>

**Commercial Telegram bot that builds professional, ATS-friendly CVs end-to-end: chat-based data collection, AI-assisted writing, manual payment review, and PDF + Word delivery.**

---

## ✨ المميزات

- **إنشاء سيرة ذاتية بالمحادثة** — أسئلة تفاعلية خطوة بخطوة بالعربية أو الإنجليزية
- **ملخص مهني بالذكاء الاصطناعي** — كتابة تلقائية مخصصة للمسمى الوظيفي المستهدف
- **15 قالبًا** — تصاميم ATS والتصاميم العصرية (6 قوالب جاهزة)
- **دعم كامل للعربية** — RTL صحيح، تشكيل الحروف، ونقاط تعداد متوافقة مع العربية
- **صورة شخصية اختيارية** — رفع وقص تلقائي بمقاس 1:1
- **استيراد PDF/DOCX** — يقرأ سيرتك القديمة ويعبئ البيانات تلقائيًا
- **التسليم التجاري** — ملف PDF نهائي + Word قابل للتعديل + خطاب تقديم مجاني
- **الدفع اليدوي** — عبر كي كارد بمراجعة إدارية قبل التسليم
- **نظام التعديلات** — أول تعديلين مجانًا، وإصلاح أخطاء النظام مجاني دائمًا
- **مركز إدارة متكامل** — لوحة تحكم، إذاعة، اشتراك إجباري، نظام إحالة، ترحيب
- **بوابة جودة إلزامية** — فحص تلقائي قبل كل تسليم يمنع الأخطاء والتسريبات

## 🔄 رحلة المستخدم

```
1. /start → إنشاء سيرة جديدة
2. اختيار اللغة (عربي / إنجليزي)
3. إدخال البيانات (الاسم، الهاتف، التعليم، الخبرات، المهارات...)
4. كتابة الملخص المهني بالذكاء الاصطناعي
5. اختيار القالب + الصورة الشخصية (اختياري)
6. معاينة بعلامة مائية
7. الدفع عبر كي كارد + إرسال الإيصال
8. مراجعة الإدارة والموافقة
9. استلام PDF + Word + خطاب التقديم 🎉
```

**السعر:** 5,000 د.ع للسيرة الواحدة

## 🛠️ التقنيات

- **Python 3** + `python-telegram-bot` — منطق البوت والمحادثات
- **ReportLab** — توليد PDF مع دعم RTL والعربية (`arabic-reshaper`)
- **كاتب DOCX مخصص** — WordprocessingML خفيف بدون اعتماديات ثقيلة
- **SQLite** — قاعدة البيانات (`*.db` غير منشورة)
- **Pillow** — معالجة الصور والقص التلقائي
- **OpenRouter** — نماذج ذكاء اصطناعي مجانية قابلة للتبديل من لوحة الإدارة

## 📦 التثبيت

```bash
# 1. استنساخ المستودع
git clone https://github.com/tahagamer712-beep/CVBot.git
cd CVBot

# 2. تثبيت الاعتماديات
pip install -r requirements.txt

# 3. إعداد متغيرات البيئة
cp .env.example .env   # ثم عبئ القيم الحقيقية
chmod 600 .env

# 4. رفع الخطوط يدويًا إلى مجلد fonts/
# (Amiri, Cairo — ملفات TTF)

# 5. التشغيل
bash run_cvbot.sh
```

## ⚙️ الإعداد (`.env`)

```env
BOT_TOKEN=ضع_توكن_البوت_هنا
ADMIN_ID=ضع_الايدي_الرقمي_للأدمن_هنا
KEYCARD_NUMBER=ضع_رقم_بطاقة_الدفع_هنا
SECRET_KEY=مفتاح_عشوائي_طويل
```

> ⚠️ **ملف `.env` لا يُرفع أبدًا إلى Git** — هو مستبعد في `.gitignore` مع
> قواعد البيانات (`*.db`) ومجلد الطلبات (`orders/`) وملفات الجلسات.

## 🔒 الأمان

- بيانات المستخدم هي مصدر الحقيقة — **يُمنع اختراع أي معلومة**
- لا ملف نهائي قبل موافقة الدفع + اجتياز فحص الجودة
- بوابة الجودة تمنع تسليم أي ملف فيه بيانات اختبارية أو تسريب
- الأسرار في `.env` فقط — لا تُكتب في الكود ولا في السجلات
